Trials Queue Browser Dashboard

Open this file in your browser, load an Excel workbook downloaded from Excel for web, work the queue, then download the updated workbook. No Python, Tkinter, or hosted server required.

Excel for web note: a normal browser page cannot directly save changes into an already-open Excel Online workbook. This dashboard edits the workbook in your browser and downloads an updated `.xlsx` copy for upload/replace in SharePoint. Direct live Excel Online editing would require a Microsoft Office Add-in or Microsoft Graph integration.
